# Nedo-Phantom

**Nedo-Phantom** — учебный C2 (Command & Control) фреймворк на Go для изучения сетевого программирования, системных вызовов, криптографии и архитектуры клиент-серверных приложений.

## Что уже работает

| Компонент | Статус | Описание |
|-----------|--------|----------|
| Агент (Linux) | Работает | Подключается к C2, запускает /bin/bash через PTY |
| Агент (Windows) | Работает | Подключается к C2, запускает cmd через pipes |
| C2 сервер | Работает | Слушает порт 4444, принимает агентов |
| Интерактивный шелл | Работает | Полноценный терминал через PTY (Linux) |
| Raw терминал | Работает | Правильная обработка спецсимволов на сервере |
| Переподключение | Работает | Автоматическое восстановление связи при обрыве |
| Шифрование | Работает | RSA + AES-GCM, обмен ключами |
| SecureConn обертка | Работает | Автоматическое шифрование/расшифровка |
| CLI команды | Работает | /help, /tasks, /add, /exit |
| Очередь задач | Работает | Добавление и хранение задач |
| Система задач | В разработке | Агент опрашивает задачи в фоне |
| Модули | Частично | exec, info — есть, интеграция в процессе |
| Web UI | Нет | Отсутствует интерфейс управления |
| Мультиагентность | Частично | Есть map агентов, нет управления задачами |

## Сборка и запуск

### Локальная сборка

```bash
# Собрать C2 сервер
go build -o bin/c2-server ./cmd/c2

# Собрать агента для Linux
go build -o bin/agent-linux ./cmd/agent

# Собрать агента для Windows (кросс-компиляция)
GOOS=windows GOARCH=amd64 go build -o bin/agent-windows.exe ./cmd/agent
```

### Запуск

**Терминал 1 — C2 сервер:**
```bash
./bin/c2-server
```

**Терминал 2 — Агент:**
```bash
./bin/agent-linux -server localhost:4444
```

После подключения вы получите интерактивный шелл на удаленной машине. Весь трафик шифруется.

## Как это работает

### 1. Агент (`internal/agent/core/`)

- **agent.go** — бесконечный цикл подключения к C2. При успешном соединении:
  1. Генерирует RSA ключи
  2. Отправляет публичный ключ серверу
  3. Получает и расшифровывает AES ключ
  4. Создает защищенное соединение
  5. Отправляет hostname и запускает шелл + TaskHandler в фоне

- **shell.go** — определяет ОС и создает интерактивный шелл:
  - Linux/macOS: создает PTY через /dev/ptmx, запускает /bin/bash
  - Windows: использует pipes для stdin/stdout/stderr, запускает cmd
  - Игнорирует JSON-сообщения, чтобы не ломать шелл

### 2. C2 сервер (`internal/c2/core/`)

- **server.go** — слушает порт, принимает агентов:
  1. Получает публичный ключ агента
  2. Генерирует AES ключ
  3. Шифрует его через RSA публичный ключ
  4. Отправляет зашифрованный ключ агенту
  5. Переводит терминал в raw-режим
  6. Запускает интерактивный режим с обработкой JSON

- **session.go** — управление сессией агента (состояние, ключи, время жизни)

### 3. Терминал (`internal/c2/terminal/`)

- **terminal.go** — инкапсулирует работу с raw-режимом:
  - `Raw()` — включение raw-режима
  - `Restore()` — восстановление терминала

### 4. Обработка сообщений (`internal/c2/handler/`)

- **message.go** — парсинг JSON и маршрутизация:
  - `get_task` → выдача задачи из очереди
  - `result` → обработка результата задачи

### 5. CLI (`internal/c2/cli/`)

- **command.go** — команды оператора:
  - `/help`, `/tasks`, `/add <type> [data]`, `/exit`

### 6. Шифрование

- **agent/crypto/** — RSA + AES-GCM для агента (реализует Cipher)
- **c2/crypto/** — генерация AES ключей и шифрование через RSA (реализует Cipher)
- **common/secure_conn.go** — обертка для автоматического шифрования/расшифровки

### 7. Очередь задач

- **db/tasks.go** — хранилище задач в памяти с потокобезопасностью
- **cli/command.go** — добавление задач через `/add`
- **tasks/tasks.go** — агент опрашивает задачи в фоне

## План развития

### 1. Система задач (в процессе)
- Интеграция TaskHandler в агента (уже запускается в горутине)
- Агент выполняет задачи из очереди в фоне
- Результаты отправляются на сервер

### 2. Модули
- `exec` — выполнение команд
- `info` — сбор информации о системе
- `upload` — загрузка файлов на агент
- `download` — скачивание файлов с агента
- `screenshot` — снятие скриншотов
- `persistence` — установка автозапуска

### 3. Web UI
- Веб-интерфейс для управления агентами
- REST API + WebSockets

### 4. Улучшения
- Поддержка macOS
- Мультиагентность — список агентов, выбор активного
- Pivot (перемещение по сети)
- Автономное выполнение задач
