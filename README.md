# Nedo-Phantom

**Nedo-Phantom** -- это учебный C2 (Command & Control) фреймворк на Go для изучения сетевого программирования, системных вызовов и разработки безопасного ПО. Проект разрабатывается с целью прокачки навыков в Go и понимания архитектуры клиент-серверных приложений.

## Что уже работает

| Компонент | Статус | Описание |
|-----------|--------|----------|
| + Агент (Linux) | Работает | Подключается к C2, запускает `/bin/bash` через PTY |
| + Агент (Windows) | Работает | Подключается к C2, запускает `cmd` через pipes |
| + C2 сервер | Работает | Слушает порт 4444, принимает агентов |
| + Интерактивный шелл | Работает | Полноценный терминал через PTY (Linux) |
| + Raw терминал | Работает | Правильная обработка спецсимволов на сервере |
| + Переподключение | Работает | Автоматическое восстановление связи при обрыве |
| - Шифрование | Работает | Автоматическое шифрование / расшифровка |
| `SecureConn` обертка | Работает | Автоматическое шифрование/расшифровка |
| +- Система задач | Заготовка | Есть структуры, но логика не реализована |
| +- Модули | Заготовка | Есть `executor.go`, но не интегрирован |
| - Web UI | Нет | Отсутствует интерфейс управления |
| - Мультиагентность | Частично | Есть `map` агентов, но нет управления задачами |

## Сборка и запуск

### Локальная сборка

```bash
# Собрать C2 сервер
go build -o bin/c2-server ./cmd/c2

# Собрать агента для Linux
go build -o bin/agent-linux ./cmd/agent

# Собрать агента для Windows (кросс-компиляция)
GOOS=windows GOARCH=amd64 go build -o bin/agent-windows.exe ./cmd/agent
```
# Собрать всё сразу

make all   # если есть Makefile
```
Запуск
- Терминал 1 — C2 сервер:

```bash
./bin/c2-server
```
- Терминал 2 — Агент:

```bash
./bin/agent-linux -server localhost:4444
После подключения вы получите интерактивный шелл на удаленной машине.
```

Как это работает
1. Агент (internal/agent/core/)
- `agent.go` -- бесконечный цикл подключения к C2. При успешном соединении отправляет hostname и запускает шелл.
- `shell.go` -- определяет ОС и создает интерактивный шелл:
Linux/macOS: создает PTY (псевдо-терминал) через `/dev/ptmx`, запускает `/bin/bash`.
- Windows: использует pipes для `stdin/stdout/stderr`, запускает cmd.

2. C2 сервер (internal/c2/server/)
- `server.go` -- слушает порт, принимает агентов, сохраняет сессии в `map[string]*AgentSession`.
- При подключении агента переводит терминал сервера в raw-режим (для корректной работы спецсимволов).
- Запускает две горутины для ретрансляции данных между сокетом и терминалом.
- После завершения сессии восстанавливает настройки терминала.

3. Общие структуры (internal/common/)
- `protocol.go`-- определяет структуры задач (Task) и результатов (TaskResult) для будущей системы задач.

4. Шифрование
- 6 шагов: `RSA генерация` → `отправка PEM` → `шифрование AES` → `расшифровка` → `AES-GCM` → `SecureConn`

План развития
1. Система задач (приоритет)
- Агент опрашивает задачи вместо интерактивного шелла.
- C2 выдает задачи из очереди.
- Агент выполняет и отправляет результат.

2. Модули
- exec -- выполнение команд (уже есть заготовка).
- upload -- загрузка файлов на агент.
- download -- скачивание файлов с агента.
- screenshot -- снятие скриншотов.
- persistence -- установка автозапуска.
- info -- сбор информации о системе.

3. Web UI
- Веб-интерфейс для управления агентами (список агентов, отправка задач, просмотр результатов).
- REST API + WebSockets.

5. Улучшения
- Поддержка macOS.
- Обход антивирусов.
- Pivot (перемещение по сети).
- Автономное выполнение задач.
